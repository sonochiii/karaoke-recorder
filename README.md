# GarageBand Style Karaoke & Voice Recorder

カラオケ音源のキー変更と、オケを聴きながらのマルチトラック風マイク同時録音・ミックス編集がブラウザ上で行えるWebアプリケーションです。

## 使い方
1. GitHubリポジトリに `index.html` と `README.md` を配置します。
2. GitHub Pagesを有効にしてアクセスします。
3. 音源を読み込み、キーを調整後、「オケに合わせて歌声を録音開始」を押してマイクから歌を録音します。
4. 「音源と歌声をミックスする」ボタンで、1つの歌ってみた音源としてプレビュー・ダウンロードが可能です。
